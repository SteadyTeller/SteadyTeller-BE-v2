# 통계 연동 계약

## 1차 MVP 범위

통계는 `Schedule`과 `ScheduleItem`에 저장된 데이터를 읽어 집계만 합니다.
학습 완료 상태를 변경하거나 스케줄을 수정하지 않습니다.

- 전체 학습 항목 수
- 완료 항목 수
- 기간 완료율
- 목표별 진행률
- 날짜별 완료 현황
- 총 계획 학습시간
- 연속 학습일

## 학습 현황과 통계의 차이

- 학습 현황: 오늘 할 일, 진행 중인 일, 남은 일 등 현재 스케줄을 보여주는 화면
- 통계 대시보드: 일정 기간이나 목표 전체의 수행 결과를 집계하는 화면

## 필요한 조회 데이터

| 값 | 출처 | 용도 |
| --- | --- | --- |
| `scheduleItemId` | `ScheduleItem.id` | 학습 항목 식별 |
| `goalId` | `Schedule.goalId` | 목표별 집계 |
| `scheduledDate` | `ScheduleItem.date` | 기간·날짜별 집계 |
| `plannedMinutes` | `ScheduleItem.allocatedMinutes` | 계획 학습시간 합계 |
| `completed` | `ScheduleItem.status == FINISHED` | 완료율·진행률 계산 |

## 완료 상태 연동

사용자가 학습 완료를 선택하면 Schedule 도메인이 해당 `ScheduleItem`의 상태를
`FINISHED`로 변경해야 합니다. 통계 도메인은 이 상태를 조회하여 계산합니다.

```text
학습 완료 선택
→ ScheduleItem 상태를 FINISHED로 변경
→ Statistics가 상태 조회
→ 기간 완료율과 목표 진행률 계산
```

## 제공 API

- `GET /api/v1/statistics/summary?startDate=&endDate=`: 기간 요약
- `GET /api/v1/statistics/daily?startDate=&endDate=`: 날짜별 현황
- `GET /api/v1/statistics/goals/{goalId}`: 목표별 진행률

## 2차 MVP 범위

`StudyRecord`를 도입할 때 실제 학습시간, 예상시간 정확도, 이해도, 미완료 사유,
부족한 개념 추천을 별도로 추가합니다.
